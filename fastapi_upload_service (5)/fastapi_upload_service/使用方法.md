## FastAPI 文件上传服务

### 功能
上传文件并保存到uploads文件夹；视频保存成功后，会自动在后台运行 cv 组的 `process_video.py` 处理该视频。

### process_video.py 配置
- 默认路径：项目根目录下的 `cv/process_video.py`
- 可通过环境变量 `PROCESS_VIDEO_SCRIPT` 指定自定义路径，例如：
  ```
  set PROCESS_VIDEO_SCRIPT=C:\path\to\cv\process_video.py
  ```
- 若脚本不存在，会静默跳过，不影响上传流程
- `process_video.py` 会收到一个参数：已保存视频的绝对路径
- 处理结果：`cv/result.json`（OCR 结果）、`cv/frames/`（抽帧图片）、`cv/run_status.json`（运行状态）

### 判断 Test02/process_video 是否运行
- 浏览器访问：`http://127.0.0.1:8000/cv/status` 查看最近一次处理状态
- 返回 `ran: true` 表示已运行过，可查看 `success`、`video_name`、`frame_count` 等字段
- 或直接查看 `cv/run_status.json` 文件

### 启动步骤
首先，在  fastapi_upload_service  文件页面启动cmd；
然后，在cmd中输入  .venv\Scripts\activate.bat  启动环境；
再，输入  pip install -r requirements.txt  安装依赖（第一次使用）；
最后，输入 uvicorn main:app --reload  启动后端（ FastAPI 服务）；

（不要关闭cmd窗口）
### 上传视频步骤
首先，在浏览器中打开网址  http://127.0.0.1:8000/docs  ；
然后，点击  post（绿色方框）；
再，点击  try it out （最右边黑色框）；
最后，上传文件（支持推拽上传）点击execute（蓝色框）；

### 关闭步骤
打开之前没有关闭的cmd窗口，按Ctrl + C之后输入  deactivate  （关闭后端）；
